# Changelog

All meaningful changes to the public Resonance Lab measurement format and published records should be documented here.

## 2026-08-22 — Initial public archive foundation

- Added Resonance Lab Measurement Schema `1.0.0`.
- Added a complete draft `measurement.template.json`.
- Added stable cross-product `DSR-SETUP-NNNN` setup identity.
- Defined immutable `RL-YYYY-NNNN` measurement IDs.
- Defined publication states: draft, published, superseded and withdrawn.
- Added RPM/W&F, 1–40 Hz vibration, resonance-prediction, combined-analysis and stylus-usage structures.
- Added publication policy, CC BY 4.0 licence, citation metadata and contribution policy.
- Added initial public measurement index.
