# Contributing to Resonance Lab Measurements

This repository is initially a **curated Direct Sound Records archive**. External measurement submissions are not yet open.

The reason is methodological rather than restrictive: Resonance Lab's public measurement format is new, and the metadata requirements, repeatability rules and acceptance criteria should mature against real DSR measurements before community submissions are accepted.

## What is welcome now

Issues reporting any of the following are welcome:

- schema ambiguity or validation problems;
- missing metadata that would materially improve repeatability;
- unclear units or terminology;
- broken links or documentation errors;
- suggestions for better machine-readable representation that preserve historical compatibility.

## What is not accepted yet

Please do not submit third-party measurement records or pull requests adding personal setup measurements at this stage.

## Future submissions

When external measurement contributions open, records will be expected to:

- use the current public JSON Schema;
- identify the physical setup and measurement conditions;
- distinguish predicted resonance from measured vibration;
- preserve app and analysis-method versions;
- state limitations and provenance;
- avoid guessing unknown metadata;
- include repeat measurements when the method requires them.

The contribution policy will be revised before community submissions are enabled.
